Restaurant Inventory Management System

This is a Python project I built as part of my journey into programming. The idea was to create a simple system that can help a restaurant keep track of its products, stock, sales and profit.

I wanted to put what I've been learning in Python into practice by building something useful.

What the Program Can Do

- Add new products to the inventory.
- Update product details and prices.
- Remove products from the inventory.
- Check available stock.
- Get alerts when products are running low.
- Record sales and automatically reduce stock.
- Calculate total sales revenue.
- Calculate gross profit.
- View sales history.
- Identify the best-selling product.
- Generate sales and inventory reports.

Tools and Concepts Used

- Python
- JSON for saving data
- Functions
- Lists and dictionaries
- Loops and conditional statements
- File handling
- Datetime

Project Files

- "main.py" – Contains the main program.
- "inventory_data.json" – Stores product and stock information.
- "sales_history.json" – Stores recorded sales.

The JSON files are created by the program when it runs and saves data.

How to Run the Program

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

python main.py

The program can also be run on Android using Pydroid 3.

What I Learned

Building this project helped me understand how different Python concepts work together in a real application.

I got practical experience with functions, loops, dictionaries, lists, file handling and JSON. I also learned how to save data so it remains available when the program is closed and opened again.
